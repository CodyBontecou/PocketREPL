Added `.accessibilityElement(children: .combine)` to group related elements:

### ChatView.swift
- ✅ MessageBubble - combines avatar, role label, and message text into single accessible element
- ✅ ToolCallBubble - combines tool icon, name, status, and parameters
- ✅ ToolResultBubble - combines status icon, label, and output text
- ✅ EscherTypingIndicator - ignores children, provides single "AI is thinking" label
- ✅ AIUnavailableBanner - combines warning icon, title, subtitle, and chevron
- ✅ ContextCounter - ignores children (progress bar + text), provides single descriptive label

### ModelManagementView.swift
- ✅ InstalledModelRow - combines model icon, name, badges, size, and status into single element
- ✅ DownloadableModelRow - combines model info, description, badges into single element
- ✅ DownloadProgressRow - ignores children, provides progress label with ETA

### FileBrowserView.swift
- ✅ FileRow - combines file icon, name, size, extension badge into single element

All grouped elements now have custom accessibilityLabel properties that read naturally as a single entity.
