## Goal
Add a specialized local coding model backend that the agent can call for generation/refinement while keeping the app fully offline.

## Completed

All implementation tasks finished. The PocketREPL app now has a complete local model integration layer.

### Files Created (PocketREPL/LLM/)

1. **ModelBackend.swift** - Core abstraction
   - `ModelState`, `ModelError` enums
   - `GenerationRequest`, `GenerationResponse` structs
   - `StreamedGeneration` async sequence
   - `ModelConfiguration`, `ModelInfo` structs
   - `ModelBackend` protocol (actor)
   - `ModelBackendManager` (@MainActor)

2. **MockModelBackend.swift** - Test implementation
   - Simulates model loading and generation
   - Template responses for different tasks
   - Useful for UI development

3. **PromptTemplates.swift** - Prompt formatting
   - `codeGeneration()`, `codeFix()`, `codeCompletion()`, `codeRewrite()`
   - `agentWorkflow()` for full agent prompts
   - `parseToolCall()`, `extractCode()` helpers
   - `PromptBuilder` fluent API

4. **LlamaBackend.swift** - llama.cpp integration
   - Full `ModelBackend` conformance
   - `LlamaContext` wrapper (placeholder for C bindings)
   - `ModelDiscovery` utilities for finding models
   - Setup documentation for llama.cpp integration

5. **CodingModelTool.swift** - Tool wrappers
   - `CodingModelTool` - Tool protocol conformance
   - `FixCodeTool` - Specialized fix tool
   - `AutonomousFixLoop` - Generate→Write→Run→Fix loop
   - `FixLoopProgress`, `FixLoopResult`, `FixLoopError`

6. **LocalModelOrchestration.swift** - Integration layer
   - `LocalModelOrchestrator` - Guarded generation
   - `OrchestrationGuardrails` - Token/time/memory limits
   - `GenerationOptions` - Request configuration
   - `GenerationOutcome`, `FallbackReason` - Result types
   - Memory pressure monitoring, timeout handling
