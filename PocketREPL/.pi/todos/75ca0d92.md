## Goal
Create the core runtime type that owns a session-scoped `JSContext` and returns structured execution data.

## Scope
- Define the runtime owner/actor lifecycle
- Define execution result fields for output, exceptions, and return values
- Support reset behavior for new sessions

## Acceptance criteria
- The runtime owns one JS context per session
- Execution returns structured data instead of ad hoc strings
- Resetting the runtime clears in-memory state cleanly
