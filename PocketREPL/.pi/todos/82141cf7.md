## Completed

Created `CodingModelTool.swift` with tools and helpers for integrating the local model into the agent loop.

### Components

**CodingModelTool (Tool):**
- Conforms to existing Tool protocol
- Supports 4 task types: generate, fix, complete, explain
- Parameters: task, prompt, code, error, path, max_tokens
- Integrates with ContextManager for project context
- Extracts code from markdown blocks in output
- Returns generation stats as comments

**FixCodeTool (Tool):**
- Specialized tool for code fixing
- Requires code + error parameters
- Streamlined for fix-loop integration

**Tool Descriptors:**
- `CodingToolDescriptor` with full parameter documentation
- Static descriptors for generate_code and fix_code tools
- Ready for tool documentation in prompts

**AutonomousFixLoop (actor):**
- Encapsulates the generate → write → run → fix loop
- Configurable max attempts (default: 3)
- Progress callbacks via `FixLoopProgress` enum:
  - `.generating(attempt:)`
  - `.writing(attempt:, path:)`
  - `.executing(attempt:)`
  - `.fixing(attempt:, error:)`
  - `.succeeded(attempt:)`
  - `.failed(attempts:, error:)`
- Returns `FixLoopResult` with final code and execution output

**Error Types:**
- `FixLoopError` with localized descriptions
- Cases: modelNotReady, generationFailed, maxAttemptsReached

### Integration Points

Tools use:
- `ModelBackendManager` for inference
- `ContextManager` for project context
- `PromptTemplates` for prompt formatting
- Existing `JSRuntime` and `ProjectStore` for execution

### Usage

```swift
// Add to ToolExecutor
let codingTool = CodingModelTool(
    modelManager: modelManager,
    contextManager: contextManager
)

// Or use the autonomous loop
let fixLoop = AutonomousFixLoop(
    modelManager: modelManager,
    runtime: runtime,
    projectStore: projectStore,
    contextManager: contextManager
)

let result = try await fixLoop.run(
    prompt: "Create a fibonacci function",
    filePath: "fib.js",
    onProgress: { progress in print(progress) }
)
```
