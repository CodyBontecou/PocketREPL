## Goal
Let users inspect the files the agent creates and edits.

## Scope
- Build a project-root file browser
- Support directory navigation and file selection
- Display file contents or metadata for selected entries

## Acceptance criteria
- ✅ Users can browse persisted workspace files from within the app
- ✅ File browsing reflects the active project state accurately
- ✅ The browser is driven by ProjectStore data, not duplicated filesystem logic

## Implementation

Rewrote `FileBrowserView.swift`:
- Directory navigation with back button
- `FileRow` component with type-specific icons (folder, JS, JSON, text)
- Size display for files
- Pull-to-refresh support
- `FilePreviewSheet` for viewing file contents
- Monospaced font for code files
- Error states with ContentUnavailableView
