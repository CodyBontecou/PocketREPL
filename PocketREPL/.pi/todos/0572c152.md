## Goal
Create the concrete tool surface the model will use to inspect files and run JavaScript.

## Scope
- Implement list/read/write/search tools on top of ProjectStore
- Implement `run_file` and `run_snippet` on top of JSRuntime
- Return concise, model-friendly outputs

## Acceptance criteria
- ✅ The orchestrator can access all core workspace and runtime capabilities through tools
- ✅ Tool outputs are readable and bounded  
- ✅ No tool reaches around ProjectStore or JSRuntime directly in ad hoc ways

## Implementation

Created `ToolExecutor.swift` with:
- `Tool` protocol (nonisolated, Sendable)
- `ToolExecutor` actor routing tool calls
- 6 concrete tools:
  - `list_files` - lists workspace contents with sizes
  - `read_file` - reads file with line range support
  - `write_file` - creates/overwrites files
  - `search_code` - searches JavaScript files
  - `run_snippet` - executes inline JS
  - `run_file` - executes JS file

Updated `AgentSession` with:
- `toolExecutor` property
- `executeTool(name:parameters:)` method with trace recording
- `executeTool(name:jsonParameters:)` for JSON input
- `availableTools` computed property
