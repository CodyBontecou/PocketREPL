## Completed

Rewrote `ContextManager.swift` with structured manifest and activity models:

**ProjectManifest** - Compact project state representation:
- `files: [FileEntry]` - File tree with paths, sizes, types
- `recentlyModified: [String]` - Last 5 modified files
- `lastExecution: ExecutionSummary?` - Most recent run result
- `estimatedTokens` - Token count estimate
- `render()` - Generates compact text for model context

**FileEntry** - Individual file info (path, isDirectory, sizeBytes, lineCount)

**ExecutionSummary** - Last execution state (kind, sourcePath, succeeded, errorSummary)

**ActivityRecord** - Structured activity events:
- Kind enum: prompt, toolCall, toolResult, execution, fileWrite, fileRead, sessionControl
- Replaces raw strings with typed records

**ContextBudget** - Token tracking:
- `maxTokens`, `usedTokens`, `remainingTokens`
- `allocate()` - Try to allocate tokens
- `estimateTokens()` - ~4 chars per token estimate

Manifest is cached for 5 seconds to avoid repeated filesystem scans.
