## Completed

Added `ExecutionDiagnostic` struct in `ToolExecutor.swift` with structured error categorization:

**FailureKind enum** categorizes errors:
- `syntaxError` - Parse errors, unexpected tokens
- `runtimeError` - General execution errors
- `assertionFailure` - Failed assert() calls
- `moduleNotFound` - Missing require() targets
- `typeError` - Type mismatches, not-a-function
- `referenceError` - Undefined variables

**Improved output format:**
- Category header with location: `[TYPE ERROR] at main.js:line 5`
- Primary error message
- Trimmed stack trace (max 5 lines for token efficiency)
- Additional assertion failures listed
- Module list shown for module errors

**Benefits:**
- Agent can distinguish error types for targeted fixes
- Location info makes errors actionable
- Consistent format across all execution failures
- Token-efficient output (trimmed stacks)
