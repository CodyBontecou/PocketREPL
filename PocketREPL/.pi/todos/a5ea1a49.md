## Completed

Created `LocalModelOrchestration.swift` with guardrails, fallbacks, and resource management for integrating the local model into the agent system.

### Components

**LocalModelOrchestrator (@MainActor):**
- Wraps ModelBackendManager with guardrails
- Published state: modelState, isGenerating, lastGenerationStats
- `loadModel(at:)` / `unloadModel()` lifecycle management
- `generateCode()` with full guardrails and fallback handling
- `fixCode()` with resource checks
- Memory pressure monitoring
- Timeout protection via `withTimeout()`

**OrchestrationGuardrails:**
- `maxPromptTokens`: Limit prompt size (default: 2048)
- `maxCompletionTokens`: Limit output size (default: 1024)
- `maxContextTokens`: Limit project context (default: 1000)
- `maxGenerationTimeSeconds`: Timeout (default: 60s)
- `maxConsecutiveFailures`: Retry limit (default: 3)
- Presets: `.default`, `.conservative`, `.generous`

**GenerationOptions:**
- Configurable maxTokens, temperature, streaming
- Presets: `.default`, `.creative`, `.deterministic`

**GenerationOutcome (enum):**
- `.success(code:, stats:)` - Generation completed
- `.error(ModelError)` - Model error occurred
- `.fallback(reason:)` - Guardrail triggered fallback

**FallbackReason (enum):**
- `.modelNotReady` - Model not loaded
- `.promptTooLarge(tokens:, max:)` - Input too large
- `.resourceConstrained(String)` - Memory pressure
- `.timeout(seconds:)` - Generation took too long
- `.tooManyFailures(count:)` - Consecutive failures

**GenerationStats:**
- Token counts, duration, speed metrics
- `formattedSpeed` and `formattedDuration` for UI

**Utilities:**
- `withTimeout()` - Async operation with timeout
- Memory pressure detection via mach_task_basic_info

### Integration

The orchestrator can now:
1. Check model readiness before generation
2. Verify memory availability
3. Estimate and limit token counts
4. Enforce generation timeouts
5. Cancel and recover from stuck generations
6. Report why fallback occurred
7. Track generation statistics

### Usage

```swift
let localOrchestrator = LocalModelOrchestrator(
    modelManager: modelManager,
    contextManager: contextManager,
    guardrails: .default
)

// Load model
try await localOrchestrator.loadModel(at: modelPath)

// Generate with guardrails
let outcome = await localOrchestrator.generateCode(
    prompt: "Create a REST API client",
    filePath: "api.js",
    options: .default
)

switch outcome {
case .success(let code, let stats):
    print("Generated \\(stats.completionTokens) tokens in \\(stats.formattedDuration)")
case .fallback(let reason):
    print("Falling back: \\(reason)")
case .error(let error):
    print("Error: \\(error)")
}
```
