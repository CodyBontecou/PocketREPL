## Goal
Make file-based JavaScript execution feel natural without forcing the model to manually load modules.

## Scope
- Resolve relative module paths from the current file
- Load JS source from the active project store
- Wrap modules with CommonJS semantics and cache exports per session

## Acceptance criteria
- `require('./utils/parser')` works from a JS file in the workspace
- Requiring the same module twice reuses cached exports unless reset
- Module loading errors surface clearly to the caller
