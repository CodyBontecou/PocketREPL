## Completed

Implemented in `ContextManager.swift`:

**assembleContext(budget:)** - Main context assembly method:
1. Generates project manifest (priority 1)
2. Adds recent activity (priority 2, truncated if needed)
3. Respects token budget throughout
4. Returns assembled string for prompt injection

**Token budgeting:**
- `ContextBudget` struct tracks usage
- `allocate()` returns false if over budget
- Activities truncated with "... (truncated)" marker

**Incremental updates:**
- `recordFileAccess(isWrite:)` - Invalidates manifest cache on writes
- `recordExecution()` - Captures JSExecutionResult summary
- Manifest cached for 5 seconds to avoid repeated scans

**Truncation rules:**
- Max 100 files in manifest
- Max 50 activities retained
- Max 20 recent file paths
- Last 10 activities included in context
- Last 5 modified files in manifest

The orchestrator can call `await contextManager.assembleContext(budget: 2000)` on each turn.
