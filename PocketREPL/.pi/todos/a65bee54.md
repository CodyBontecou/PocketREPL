## Goal
Complete the llama.cpp integration to enable real on-device inference, replacing the placeholder LlamaContext with working C bindings.

## Scope
- Add llama.cpp as a git submodule
- Configure Xcode for C++ interop with Swift
- Implement real llama_* C function calls in LlamaContext
- Add model discovery, download, and management
- Build UI for model loading and status

## Deliverables
- Working local inference on iPhone/iPad
- Model management UI for loading/unloading models
- Support for GGUF models (Qwen2.5-Coder-1.5B recommended)

## Acceptance Criteria
- User can load a GGUF model and generate code locally
- Model loading shows progress
- Generation streams tokens to the UI
- App handles low memory gracefully
- Works offline with no network dependency

## Notes
- Target Q4_K_M or Q4_K_S quantization for mobile
- Consider 1.5B-3B parameter models for iPhone
- Metal GPU acceleration is optional but beneficial

## Priority
- Priority: P0
- Rationale: This is the final piece to make the app fully functional offline
