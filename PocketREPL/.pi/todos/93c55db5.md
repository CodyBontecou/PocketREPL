## Goal
Create the session object that owns the Foundation Models interaction loop.

## Scope
- Instantiate the language model session with instructions and tools
- Add APIs like `send`, `resetRuntime`, and `newSession`
- Keep orchestration logic out of views

## Acceptance criteria
- ✅ A prompt can be submitted through one session API
- ✅ The session owns model/tool orchestration cleanly  
- ✅ Runtime reset and new-session behavior are explicit

## Implementation

Created `FoundationModelsAdapter.swift`:
- `AgentOrchestrator` class that processes prompts and executes tools
- Foundation Models integration (when available on iOS 26+)
- Fallback mode that allows direct tool invocation for testing
- `process()` method with callbacks for messages, tool calls, and results

Updated `AgentSession`:
- Added `orchestrator` property
- Updated `send()` to use orchestrator with proper callbacks
- Added `resetRuntime()` - clears JS module cache
- Added `newSession()` - clears messages, trace, and resets state
- Updated system prompt with tool instructions
