## Goal
Create the core conversational interface for interacting with the agent.

## Scope
- Build a message list for user and assistant messages
- Add prompt input and send affordance
- Handle loading/running states in the chat flow

## Acceptance criteria
- ✅ Users can enter a prompt and see responses in a readable thread
- ✅ The chat UI handles long content gracefully
- ✅ The view is suitable for an iPhone-first layout

## Implementation

Created `ChatView.swift`:
- `ChatView` - Main chat interface with message list and input bar
- `MessageBubble` - Styled message bubbles with user/assistant differentiation
- `TypingIndicator` - Animated dots while processing
- Auto-scroll to bottom on new messages
- Multi-line input with submit on Enter
- Disabled input while processing

Updated `AgentView.swift`:
- Uses ChatView for conversation
- Toolbar with tool trace and session menu
- Tool trace sheet with ToolTraceRow components
- Session controls (reset runtime, new session)
