## Goal
Make project workspaces easy to create, reopen, and persist across app launches.

## Scope
- Add APIs for creating/opening named workspaces
- Ensure the workspace root is created on demand
- Surface lightweight metadata useful for relaunch and browsing

## Acceptance criteria
- A named workspace can be created and reopened reliably
- Workspace data survives relaunches
- The app has a clear entry point for opening the active project

Completed on 2026-03-10.

Added workspace lifecycle helpers:
- `restore(defaultWorkspaceName:)`
- `createWorkspaceIfNeeded()`
- persisted workspace metadata in `.pocketrepl/workspace.json`
- active workspace bookmark persistence in `UserDefaults`
- `listKnownWorkspaces(...)` for lightweight relaunch/browsing metadata
