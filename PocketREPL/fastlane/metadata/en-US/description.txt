PocketREPL is an on-device AI coding workspace that runs fully offline.

Build, test, and iterate with an autonomous assistant directly on your iPhone or iPad. No cloud execution, no account required, and no data leaves your device.

HOW IT WORKS

• Start with a prompt describing what you want to build
• PocketREPL writes code, runs it, and inspects the result
• If something breaks, it can iterate and fix issues automatically
• You can inspect files, edit output, and guide each next step

WHAT YOU CAN DO

• Prototype utilities and scripts quickly
• Explore ideas with conversational coding
• Test logic in a local sandbox
• Inspect and manage project files in one workspace
• Use built-in docs to understand tools and workflows

LOCAL MODELS + APPLE INTELLIGENCE

PocketREPL supports Apple’s on-device intelligence when available and can also run local GGUF models for coding-focused tasks.

• Private by default
• Works without internet
• Flexible model options based on your device

IMPORTANT LIMITATIONS

This is still early-generation local AI.

• Context is limited compared with cloud models
• Complex multi-file projects may require manual guidance
• Large tasks can be slower on mobile hardware

PocketREPL is best for experimentation, learning, and rapid prototyping on-device.

PRIVACY

Your prompts, files, and execution stay on your device. PocketREPL does not require cloud processing for core functionality.
