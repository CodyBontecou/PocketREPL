## Completed

Added bounded retry state tracking in `FoundationModelsAdapter.swift`:

1. **RetryState struct** - Tracks:
   - `consecutiveFailures` - count of failures on same error
   - `lastFailureSignature` - normalized error for deduplication
   - `totalExecutions` and `totalFailures` for stats

2. **recordToolResult()** - Updates retry state after run_snippet/run_file
   - Resets on success
   - Increments on failure with same error signature
   - Returns true when limit reached

3. **errorSignature()** - Normalizes error messages by stripping line numbers

4. **processWithFallback()** - Now checks retry limit before execution
   - Blocks further execution after maxConsecutiveFailures (default 3)
   - Shows clear message asking user for guidance

5. **OrchestrationResult** - Added `stoppedDueToRetryLimit` field

The agent now stops after 3 consecutive failures on the same error instead of looping forever.
