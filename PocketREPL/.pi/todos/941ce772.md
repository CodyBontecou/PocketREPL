## Goal
Create a single storage abstraction for agent projects so files persist reliably and later sync cleanly through iCloud.

## Scope
- Introduce a `ProjectStore` abstraction instead of using raw `FileManager` in tools
- Support project root creation, safe relative path resolution, read/write/list/search helpers
- Prevent path traversal (`../`) and invalid writes outside the project root
- Design for local-first behavior with an iCloud-compatible storage layout
- Surface lightweight project metadata/manifests needed by the agent

## Deliverables
- `ProjectStore.swift` with CRUD and listing APIs
- Path normalization and validation utilities
- Project bootstrap logic for creating/opening named workspaces
- Search helpers for JavaScript source files

## Acceptance criteria
- Files can be created, read, updated, listed, and searched through one API
- Unsafe paths are rejected
- Workspace data survives app relaunches
- Storage design is compatible with a later iCloud container migration without a broad refactor

## Notes
This should become the only layer that knows where projects live on disk.
