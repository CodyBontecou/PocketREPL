## Completed

Metal GPU acceleration is already integrated via the llama.xcframework:

### What's Included
- ✅ `ggml-metal.m` and `ggml-metal.metal` compiled into framework
- ✅ Metal.framework and Accelerate.framework linked
- ✅ GGML_USE_METAL enabled in build
- ✅ BF16 support enabled for Apple Silicon

### Configuration in LlamaBackend
```swift
#if targetEnvironment(simulator)
let gpuLayers = 0 // CPU only on simulator (no Metal)
#else
let gpuLayers = 99 // Offload all layers to GPU on device
#endif

var modelParams = llama_model_default_params()
modelParams.n_gpu_layers = Int32(gpuLayers)
```

### Build Flags Used
From `build-xcframework.sh`:
- `GGML_METAL=ON`
- `GGML_METAL_EMBED_LIBRARY=ON`
- `GGML_METAL_USE_BF16=ON`
