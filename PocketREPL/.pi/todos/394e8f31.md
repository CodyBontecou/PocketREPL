## Completed

Added `@Environment(\.accessibilityReduceMotion)` checks to all animated views:

### EscherDesignSystem.swift
- ✅ MetamorphosisWave - guards `withAnimation` in `.onAppear { guard !reduceMotion else { return } ... }`
- ✅ InfiniteStairs - shows static middle state when reduce motion enabled, properly invalidates timer on disappear

### ChatView.swift
- ✅ MessageBubble - entrance animation skipped when reduce motion enabled
  - Sets `appeared = true` immediately instead of animating
  - Removes offset animation (`reduceMotion ? 0 : 8`)

### FileBrowserView.swift
- ✅ FileRow - entrance animation skipped when reduce motion enabled
  - Sets `appeared = true` immediately instead of animating
  - Removes offset animation (`reduceMotion ? 0 : -8`)

All animations now respect system Reduce Motion preference (Settings > Accessibility > Motion > Reduce Motion).
