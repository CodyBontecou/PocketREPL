## Goal
Enable Metal GPU acceleration for faster inference on iOS devices.

## Implementation

### Build Configuration
1. Add Metal source files to Xcode:
   - `vendor/llama.cpp/ggml/src/ggml-metal.m`
   - `vendor/llama.cpp/ggml/src/ggml-metal.metal`

2. Add frameworks:
   - Metal.framework
   - MetalKit.framework

3. Add compile flags:
   - Define `GGML_USE_METAL=1`

### Metal Shader Bundle
The Metal shaders need to be compiled and bundled:
```bash
# In build phase script
xcrun -sdk iphoneos metal -c ggml-metal.metal -o ggml-metal.air
xcrun -sdk iphoneos metallib ggml-metal.air -o default.metallib
```

Or let Xcode compile `.metal` files automatically by adding them to the target.

### Configuration Updates
```swift
extension ModelConfiguration {
    static func forDevice() -> ModelConfiguration {
        let device = MTLCreateSystemDefaultDevice()
        let hasGPU = device != nil
        
        // Determine optimal GPU layers based on device
        let gpuLayers: Int
        if hasGPU {
            // Use GPU for all layers on capable devices
            gpuLayers = 99  // Will use available VRAM
        } else {
            gpuLayers = 0  // CPU only
        }
        
        return ModelConfiguration(
            modelPath: "",  // Set at load time
            contextSize: 4096,
            gpuLayers: gpuLayers,
            threadCount: ProcessInfo.processInfo.activeProcessorCount,
            useMemoryMapping: true,
            batchSize: 512
        )
    }
}
```

### Memory Management
```swift
extension LlamaContext {
    /// Check available GPU memory before loading
    static func availableGPUMemory() -> Int64? {
        guard let device = MTLCreateSystemDefaultDevice() else { return nil }
        // Note: iOS doesn't expose exact VRAM, estimate from device
        return device.recommendedMaxWorkingSetSize
    }
    
    /// Estimate memory needed for model
    static func estimateMemoryNeeded(modelSizeBytes: Int64, gpuLayers: Int) -> Int64 {
        // Rough estimate: model size + context buffer
        let contextBuffer = Int64(4096 * 4 * 1024)  // 4K context, 4 bytes per token estimate
        return modelSizeBytes + contextBuffer
    }
}
```

## Acceptance Criteria
- Metal shaders compile and bundle correctly
- GPU acceleration works on supported devices
- Falls back to CPU gracefully when GPU unavailable
- No memory crashes from GPU overallocation
- Noticeable speedup on A-series chips

## Notes
- A14+ chips have significant Metal performance
- Older devices may be better with CPU-only
- Test on physical device, not simulator
