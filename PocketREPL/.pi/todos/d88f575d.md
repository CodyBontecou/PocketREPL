## Goal
Make app startup explicitly construct the main dependencies instead of letting views own everything.

## Scope
- Add an app-level composition root or container
- Instantiate the project store, JS runtime, and agent session in one place
- Inject those dependencies into the top-level UI

## Acceptance criteria
- App startup clearly shows where core services are created
- Views do not construct storage/runtime internals ad hoc
- The composition root is ready for future dependency swapping

Completed on 2026-03-10.

- Added `AppContainer` as the explicit composition root.
- Startup now restores/creates the workspace store, context manager, runtime stub, and agent session in one place.
- `PocketREPLApp` now launches `RootView(container:)` instead of the starter template view.
